# Sample context (fictional)

Used for the first review when no tools are connected. Every name, company and number is invented. Outputs built on these files must be labelled "sample data".

- `inbox-sample.md`: eight captured items waiting to be filed.
- `matrix.sample.md`: ten scored items across the three lenses.
- `horizons.sample.md`: a filled 3 × 3 grid for a fictional head of operations.
- `watchlist.md`: six watchlist rows with dated signals.
- `outreach-queue.md`: five people with cadence and last contact.
